# Working on Nobody’s Home

Read README.md first. This repository is the browser prototype; leave the separate Unity project untouched unless the owner asks. Use `dist/assets/kitten.glb` for the existing kitten, preserve saved progress and avoid replacing working systems. Maintain the older North Kolkata setting, low-power defaults and story told from a cat's perspective. The owner wants functionality and collision/camera reliability before visual polish, and no day-number countdown presentation. Run the lightweight checks listed in README.md. Ask before running long graphical tests if the laptop is hot. The owner has requested automatic updates to the public game. After completing and checking a requested game change, commit only the intended changes and push the main branch to the github remote; GitHub Actions publishes dist automatically. Do not publish incomplete work or change access settings. If unrelated changes are present, preserve them.

Current priority: a realistic North Kolkata exterior: narrow lanes, dense worn houses, streets that are not clean. The main page is free roam; story.html retains the story and original save. The world is data in dist/explore-layout.mjs (lanes, rows of lots, props); houses, clutter and trees are generated from fixed seeds and rendered instanced. Keep lanes narrow, never repeat a house, preserve Claude’s original assets, and keep the kitten small. tests/explore.test.mjs must keep every lane and cat gap connected. Mouse movement must control the camera without dragging. Obstacle avoidance must never change the input yaw. Check tight spaces, steps/headroom, connected routes and low-power behavior before publishing.
